# Installed app icon

`app-icon-brand.png` is the opaque 1024 × 1024 launcher icon: white Radefy mark
on brand green. It is used by the main icon, iOS icon, and Android adaptive
foreground. The Android background is `#25694E`; the existing transparent
logo remains the monochrome mask for launcher-controlled themed icons.

Created using the built-in image editing tool with the existing logo as its
reference, then resized to 1024 × 1024 using `sips`. Source artwork and the
in-app/splash logo are preserved. A new native build is required to install it.

## Editing prompt

Edit this existing Radefy logo into a production app icon. Preserve the EXACT
geometry, silhouette, holes, proportions, position, and size of the original
black logo. Only recolor the logo pure white (#FFFFFF) and replace the entire
transparent/white-looking background with uniform solid brand green #25694E.
Output 1024x1024 square opaque PNG. Logo stays centered at approximately 55.5%
of canvas width and height, generous safe margins as source. No rounded outer
corners, no border, no shadow, no gradient, no texture, no text. Flat precise
logo artwork, do not redesign any aspect of the mark.
